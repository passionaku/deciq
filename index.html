Deciq memanggil model AI pilihanmu lewat API yang kompatibel dengan format OpenAI Chat Completions. Data tersimpan hanya di browser ini (localStorage).

Contoh: OpenAI, OpenRouter (.../api/v1/chat/completions), atau server lokal seperti LM Studio / Ollama (via proxy yang mendukung CORS).

Contoh: gpt-4o-mini, openai/gpt-4o-mini (OpenRouter), llama-3.1-8b (lokal).
